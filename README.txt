🐍 ЗМЕЙКА С ПУШКОМ 🐕
===================

⚡ БЫСТРАЯ HTML5 ВЕРСИЯ - БЕЗ ЛАГОВ!

📦 КАК ЗАПУСТИТЬ НА WINDOWS 11:

1. Дважды кликните на файл "ИГРАТЬ.bat"
2. ИЛИ откройте "index.html" в любом браузере (Chrome, Edge, Firefox)

🎮 УПРАВЛЕНИЕ:

- Стрелки ↑↓←→ или WASD - движение змейки
- SPACE - новая игра (после проигрыша)
- 🔊 (правый верхний угол) - вкл/выкл звук

✨ ОСОБЕННОСТИ:

✅ Сверхбыстрая работа (HTML5 Canvas)
✅ Плавная анимация без лагов
✅ Милый Пушок в качестве еды (только мордочка!)
✅ Звуковые эффекты
✅ Препятствия на карте
✅ Красивая графика с эффектами свечения
✅ Работает в любом браузере
✅ Не требует установки
✅ Весит меньше 1MB!

🚀 ПОЧЕМУ HTML5?

- Мгновенный запуск
- Нет лагов и подвисаний
- Работает везде (Windows, Mac, Linux)
- Легче чем WPF/C# версия (69MB → <1MB)

💡 СОВЕТ:

Для полноэкранного режима нажмите F11 в браузере!

Наслаждайтесь игрой! 🎉
