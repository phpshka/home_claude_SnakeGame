# Архитектурные решения — claude_SnakeGame

## 2026-02-19 — Монолитный index.html
**Решение:** весь код (HTML + CSS + JS) в одном файле
**Причина:** простота запуска, нет сборщика, можно открыть двойным кликом
**Последствия:** не разбивать на файлы без явной причины

## 2026-02-19 — Canvas API вместо DOM
**Решение:** рендеринг через Canvas
**Причина:** плавная анимация, полный контроль над отрисовкой
**Последствия:** UI-элементы поверх Canvas требуют отдельных DOM-слоёв

## 2026-02-19 — localStorage для рекордов
**Решение:** localStorage, ключи с префиксом snake*
**Причина:** нет бэкенда, данных мало
**Последствия:** рекорды хранятся только в браузере
